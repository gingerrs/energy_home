# Передача W1-C

Дата: 29.10.2026. Відповідальна за роль C: Софія.
Наступний власник та інтегратор: Діана.

## Результат

- `src/energyhome/core.py`: реалізовано розрахунковий рушій (функція `calculate_cost`, структура `CostBreakdown`).
- `tests/test_core.py`: написано автономні юніт-тести для перевірки сталого профілю, нульових/порожніх даних та дробових інтервалів із фінальним округленням.
- `docs/HANDOVER-C.md`: зафіксовано технічний контракт та архітектурні рішення модуля.

Логіка розрахунку визначає енергію інтервалу (`power_kw * step_minutes / 60`), підсумовує всі інтервали та застосовує єдине фінальне округлення до 0.01 UAH за допомогою `Decimal` із режимом `ROUND_HALF_UP`. Модуль є повністю автономним, не здійснює виводів у консоль та не виконує читання файлів.
