## Виконані локальні перевірки

На macOS пройшли всі 250 unittest окремо на Python 3.11.18 і 3.12.3.
Обидва середовища мають установлені wheel та залежності; pip check успішний.
Перевірка встановленого пакета з тимчасової папки поза checkout пройшла на
обох версіях: імпорт, help, спільний CSV, фільтр, власний JSON і поганий config.
Ruff за E/F/W, довжина рядка 100, не знайшов помилок у src/scripts/tests.
Ці локальні результати не є виконанням Windows/Linux CI.

```sh
python -m pip install .
python -m pip check
python scripts/check_install.py
python -m unittest discover -s tests -v
ruff check src scripts tests
```

Тести включають справжні subprocess-виклики CLI, DST, півкопійки через північ,
пропуски, часткові доби, невалідні metadata й timestamps, нулі й порожній відбір.
Нові тести перевіряють також колізії ключа кешу для bool/int/float, конфігурацій
SourceConfig і повторної осінньої години, а також єдине округлення двох cost API.

## Що потребує зовнішнього приймання

Фактичні результати GitHub CI та незалежні схвалення потрібно перевірити
у PR із Andrii-fix-all до main перед злиттям. Локальні перевірки не замінюють
ці кроки. Налаштування branch protection не змінені. Порядок приймання й
чотири потрібні checks описано в [review-checklist.md](review-checklist.md).

Формула нерівномірності — peak/mean; за mean=0 — None. У HANDOVER W4-C є запис
про погодження викладачем, але окремого підтвердження у репозиторії немає.
Цей факт потрібно перевірити при незалежному прийманні; локальні тести
підтверджують математичну реалізацію, а не усне погодження.
