Що було реалізовано (Роль E,тиждень 1):
Створено базову архітектуру пакета src/energyhome.
Написано CLI-парсер (cli.py) через argparse. Додано команду report із обов'язковим прапорцем --input та опціональним --tariff.
Створено тестове середовище. Написано 3 юніт-тести (tests/test_cli.py), які перевіряють логіку парсера та обробку помилок (SystemExit).
Налаштовано інфраструктуру проєкту: додано pyproject.toml для системної реєстрації пакета та .gitignore для чистоти репозиторію.

Інструкція для команди:
Витягніть останні зміни з гілки.
У кореневій папці виконайте команду  pip install -e (це зареєструє команду energyhome у вашому терміналі).
Для перевірки працездатності введіть energyhome --help.
Для запуску тестів використовуйте python -m unittest tests/test_cli.py.

Наступні кроки для інших ролей:
Парсер наразі викликає функцію-заглушку command_report(args) у файлі cli.py.
Для бізнес-логіки потрібно буде імпортувати туди свої модулі та замінити базові print() на реальний виклик функцій читання та аналізу файлу, передаючи їм args.input та args.tariff.
