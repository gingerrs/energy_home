# W3-D — потокові добові звіти та графіки

Власниця задачі: Діана. Reviewer за ротацією: Аня.

iter_daily_summaries тримає одну локальну добу, враховує DST і переносить
остаточне округлення між днями. daily_summaries використовує той самий код.
Графіки мають абсолютну вісь часу, зберігають повторну осінню годину й
відображають зміну ставки на початку інтервалу. Matplotlib імпортується
лише під час побудови графіка.

plot_device_stack приймає готові профілі приладів. Якщо є лише total,
показує його без довільного поділу. scripts/plot_demo.py використовує три
явно синтетичні CyclicDevice, сума яких збігається зі спільним CSV.
Алгоритмів розпізнавання приладів цей компонент не реалізує.

Перевірка: python -m unittest discover -s tests -v.
Файли графіків: python scripts/plot_demo.py.
Тести звіряють числові ряди, DST, точку зміни ставки та суму профілів.
Контракт: ../../spec.md. Незалежне review та усна передача — окремі кроки.
