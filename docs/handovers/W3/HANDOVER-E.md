# W3-E — період, конфігурація і декоратори

Власниця задачі: Софія. Reviewer за ротацією: Діана.

CLI підтримує незалежні --from/--to з явним timezone і --tariffs CONFIG.
Відбір виконується до розрахунків; CLI друкує готовий аналітичний результат.
cache_profile враховує bound arguments, SourceConfig, шлях і версію файла.
Iterator і винятки не кешуються. log_call зберігає результат/виняток і
метадані функції; деталі пишуться на DEBUG, очікувана помилка — один раз у CLI.
У поточному CLI кешується реєстр конфігурації, не річний потік вимірювань.

Перевірка: python -m unittest discover -s tests -v.
Адресні тести: test_cli.py, test_project_fixes.py, test_infra.py.
Погодження API, незалежне review й усна передача потребують окремого
підтвердження команди. Опис контракту: ../../spec.md.
