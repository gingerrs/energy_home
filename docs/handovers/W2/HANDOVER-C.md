Результат
Визначено незмінну доменну сутність Event(timestamp, device_id, event_type) для маркування переходів стану "on" / "off".
Реалізовано функцію detect_events(profile, on_threshold, off_threshold, label="device"):
  - Забезпечено захист від шуму за допомогою гістерезису (тригер Шмітта): перехід в on відбувається при power_kw >= on_threshold, повернення в off — при power_kw <= off_threshold.
  Реалізовано валідацію порогів: умова on_threshold <= off_threshold відхиляється викликом ValueError.
  - Чітка семантика меж: якщо на першому кроці споживання перевищує поріг, фіксується подія on; незакритий стан наприкінці профілю не генерує штучних подій off.
  - Чиста архітектура: функція повертає tuple[Event, ...], не використовує print і відокремлена від файлового I/O.
Додано 3 unit-тести у tests/test_core.py (сценарій [0,0,1,1,0], сталі/порожні профілі, шуми та крайові винятки).

Поточний стан: реалізовано двопороговий гістерезис, який відсікає шум навколо порога та перевіряє умову on_threshold > off_threshold.
