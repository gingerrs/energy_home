# Виправлення після інтеграції W2

Авторка: Anna Yarosh. База: `main`, коміт `1e86d58`.
Гілка: `anna/w2-fixes`. Стан: підготовлено для рев'ю.

## Результат

- Аналітика читає наявні `CostBreakdown.energy_kwh` і `total_cost`.
  Публічний API core збережено; документацію та unit-тести узгоджено з ним.
- `integration_analytics.py` перейменовано на `test_integration_analytics.py`,
  щоб стандартний unittest discover запускав справжню інтеграцію та CLI.
- Дні визначаються в часовому поясі тарифу. Покриття враховує фактичну
  тривалість доби на переходах годинника без заповнення прогалин.
- Тижневі підсумки розділено за понеділками, включно з межею року.
- Три DTO аналітики — frozen dataclass зі slots; formatter друкує `[start, end)`.
- Моделі приладів будують сітку в UTC; неправильні часові межі, неповні
  інтервали та дробові параметри хвилин відхиляються через ValidationError.
- Детектор відхиляє NaN, нескінченні й нечислові пороги та bool.
- Мінімальну версію Python піднято до 3.11 відповідно до імпорту datetime.UTC.
- Покажчик передач доповнено посиланнями на W2-C, W2-D і цей документ.

## Перевірка

Виконано на Python 3.12.14 з кореня репозиторію:

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
PYTHONPATH=src python3 -m energyhome report --input data/demo/meter_15min.csv --tariff single
```

101 тест: 84 попередні unit-тести, 4 інтеграційні та 13 нових перевірок.
Перевірено реальні CSV і CLI, локальну північ, обидва переходи годинника,
календарні тижні та межу року, помилкові параметри й незмінність DTO.
Згенерований профіль і збережений CSV дають ті самі дві події, що й events.csv.

## Семантика

Прилад працює за абсолютною тривалістю від початку періоду; результат у UTC.
Добовий звіт відносить інтервал до локальної дати його початку. Для точного
добового розподілу сітка має збігатися з північчю. Тиждень — понеділок–неділя;
передавати не більше одного добового звіту на дату. Вартість тижня є сумою
вже округлених добових вартостей. House поки не перевіряє сумарну потужність
проти ліміту лічильника — це чинне задокументоване обмеження W2-A.

Оригінальні передачі W1/W2 залишено історичними записами стану на час передачі.
Поточні правила та команди наведено в docs/spec.md і цьому документі.
