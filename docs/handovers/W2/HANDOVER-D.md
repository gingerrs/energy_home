# W2-D — добові й тижневі підсумки

Власниця задачі: Софія. Reviewer за ротацією: Діана.

DailySummary і WeeklySummary — незмінні dataclass із slots. Добові підсумки
групуються за timezone тарифу; покриття враховує 23/25-годинну добу та пропуски.
Поточна реалізація використовує спільний streaming accumulator із W3/W4.
Округлення переноситься між днями, тому суми показаних днів і тижнів
збігаються з фінальним core total. Пропущені дні не домислюються.

Перевірка: python -m unittest discover -s tests -v.
Тести: test_analytics.py, test_w2_regressions.py, test_project_fixes.py.
Актуальний контракт: ../../spec.md. Незалежне review й усна передача
потребують окремого підтвердження команди.
