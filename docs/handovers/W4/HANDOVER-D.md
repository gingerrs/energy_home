# W4-D — річний звіт Demo 1

Власниця задачі: Аня. Reviewer за ротацією: Маргарита.

build_annual_report повертає спостережені межі, count, енергію, гроші,
порівняння тарифів, peak, peak/mean, середню ціну та добові/тижневі таблиці.
Перший тариф базовий, другий необов'язковий. Добовий accumulator спільний
із потоковими та звичайними підсумками; сирий рік не накопичується.
Суми днів і тижнів дорівнюють final core total завдяки перенесенню округлення.
Порожні дані дають помилку; справжні нульові вимірювання зберігають період.

Контроль UCI 2008: 526845 записів, 9413.5128 kWh, single 23533.78 UAH,
two_zone 21128.57 UAH, 195 відсутніх інтервалів. Дані, інструкції,
контрольний текст і графіки: ../../demo1/README.md.
Stacked bar малого demo походить із профілів CyclicDevice, а не часток 30/70.

Перевірка: python -m unittest discover -s tests -v.
test_analytics_w4.py і test_cli.py запускають також реальну CLI-команду.
Контракт: ../../spec.md. Командне review й усна передача не замінюються
наявністю зелених тестів чи цього документа.
