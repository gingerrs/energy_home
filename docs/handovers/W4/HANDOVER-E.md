# W4-E — запуск Demo 1

Власниця задачі: Діана. Reviewer за ротацією: Аня.

Команда report читає CSV потоком, перевіряє конфігурацію, створює тарифи й
виводить build_annual_report. Сучасний і старий формат конфігурації проходять
через ту саму фабрику та той самий звіт. Відсутня ставка не підставляється.

Коди: 0 — успіх, 1 — помилка даних/конфігурації, 2 — помилка аргументів.
Нульове споживання з вимірюваннями успішне; порожній вибір — помилка.
Логи й помилки надходять у stderr; звіт — у stdout. На DEBUG є час виконання.

Встановлення й запуск:

```sh
python -m pip install -e .
python -m energyhome --help
python -m energyhome report --input data/demo/meter_15min.csv
python -m unittest discover -s tests -v
```

У test_cli.py процес дійсно читає спільний CSV; stdout порівнюється з
expected_small.txt без підміни розрахунку. Річні команди наведено в Demo 1.
Незалежне review, командне погодження API й усна передача — окремі кроки.
