# W5-B — Стиснені джерела та енергозберігальне resampling

Власниця задачі: Софія. Reviewer за ротацією: Діана.

У модулі `dataio.py` підключено потокове читання `.gz` і `.zip` без повного розпакування річного масиву в оперативну пам'ять; для `.zip` обирається один вхідний файл (або явно вказаний член архіву), тоді як невідомий чи неоднозначний файл в архіві викликає `DataImporterError`. Реалізовано `resample_readings` для агрегації до `15` або `60` хвилин із контролем одиниць (`power ↔ energy`), збереженням фізичної енергії (наприклад, `1.0 kW` протягом `4 × 15 хв` дає `1.0 kWh` при агрегації на годину), перенесенням незавершеного вікна між чанками та позначенням неповного покриття. Також додано фізичні `save_domain_json` і `load_domain_json` через domain dict без повторної доменної валідації. Увесь file IO залишається у `dataio.py`, незавершених методів і заглушок немає, а залежності `W4-B` / `W5-A` та статус звірки картки враховані для фінальної перевірки.

Перевірка: `py -m pytest`.
Тести: `test_dataio_w5.py` — однакові нормалізовані записи для `CSV`, `.gz` і `.zip` одного fixture, збереження енергії при агрегації `15 → 60` хв, поведінка на межі чанків і неповний bucket, помилки при некоректному `ZIP` та базова робота `save_domain_json` / `load_domain_json`.
Незалежне review та усна передача не засвідчуються самим цим документом.
