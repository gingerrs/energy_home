## Відтворення

Потрібен Python 3.11+. У корені репозиторію:

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

На Windows перед запуском unittest задайте `PYTHONPATH=src` способом своєї оболонки.
Додаткові бібліотеки для аналітики не потрібні.

На Python 3.12.3 проходять 20 unit-тестів: 17 нових D і 3 незмінених CLI.
Підставні об’єкти є тільки в ізольованих тестах. Вони перевіряють делегування,
порожній профіль, точний формат, межі року, незмінність входу, винятки core та
відсутність розрахунків у formatter. Цей результат не означає приймання pipeline.

Чисте wheel-встановлення з Git-знімка теж проходить ці 20 тестів. Перевірено,
що встановлений пакет не містить залишків domain/core зі старої збірки.

Окреме інтеграційне приймання після появи реальних A/C:

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -p integration_analytics.py -v
```

У поточній main цей запуск блокується відсутніми domain/core. Перевірки не
пропускаються мовчки й не замінюють реальний розрахунок mocks.

Додаткова перевірка сумісності: нова аналітика накладена на окремий знімок
збереженого pipeline `ac30475`, три інтеграційні тести пройшли. Цей знімок
не входить у гілку D і не є погодженими залежностями в main; фінальне приймання
потрібно повторити після завершення A/C/E.
