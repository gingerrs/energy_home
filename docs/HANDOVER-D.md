- `src/energyhome/cli.py`: мінімальне підключення готового formatter до команди report.

Зведення бере готові числа з core й часові межі з domain. Formatter повертає
текст із kWh/UAH, не друкує та не виконує розрахунків. CLI викликає CSV loader,
створює тариф, будує зведення та друкує його. Фіксовані 1.0 kWh видалено.

Порожній профіль або `None` від CSV loader дає відсутній період, 0 інтервалів,
0.0 kWh, 0.00 UAH та «немає даних». Нульове споживання на непорожньому
профілі зберігає його період. Реалізацій A/B/C у цій гілці немає.

## Відтворення

Потрібен Python 3.11+. Команди виконуються з кореня репозиторію:

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
PYTHONPATH=src python3 -m unittest discover -s tests -p integration_analytics.py -v
PYTHONPATH=src python3 -m energyhome report --input data/demo/meter_15min.csv
```

Останні дві команди потребують готових A/B/C. Для CLI також потрібен
`config/tariffs.demo.json` від E. На Windows задайте PYTHONPATH способом своєї оболонки.
На Python 3.12.3 усі 27 unit-тестів проходять. Тест успішного парсингу CLI
ізольований від report; реальну роботу pipeline він не підміняє.

На окремому знімку з незміненими A `879167d` і B `f9fd00a` перевірено справжній
порожній CSV через CLI: 0 інтервалів, 0.0 kWh, 0.00 UAH, код завершення 0.
Для непорожніх даних код завершення 1 чесно повідомляє про відсутній core.

Додаткова перевірка сумісності: збережені domain/core зі знімка `ac30475`,
справжній CSV loader B та поточний D/CLI проходять усі 4 інтеграційні тести.
У CLI перевірено 1.0 kWh/2.50 UAH, 2.0 kWh/5.00 UAH і порожній файл.
Цей окремий знімок не входить у гілку D і не замінює приймання командного C.

## Підключення

Підключення вже є в CLI через `_render_report`; потрібні імпорти виконуються
під час запуску report. Власникам A/B/C залишається надати погоджені модулі:

- A: LoadProfile з len/start_time/end_time, SingleZoneTariff та EnergyError.
- B: load_demo_profile(path), який повертає профіль або None для порожнього CSV.
- C: calculate_cost(profile, tariff) із total_energy_kwh і total_cost_uah.

Відсутні компоненти не замінюються розрахунком-заглушкою.
Domain/core EnergyError показується через CLI без traceback.
